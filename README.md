# WAICI: Workshop on AI and the Future of Collaborative Innovation

**Website: [ai-conference.github.io](https://ai-conference.github.io/)**

WAICI is an academic workshop held at NYU Stern School of Business in New York City, co-organized by Raveesh Mayya (NYU Stern) and Gal Oestreicher-Singer (Tel Aviv University).

- [WAICI 2026](https://ai-conference.github.io/), October 1–2, 2026: [program](https://ai-conference.github.io/program/) and [Junior Faculty Consortium](https://ai-conference.github.io/jfc/)
- [WAICI 2025](https://ai-conference.github.io/2025/), September 11–12, 2025

This repository holds the source code of the WAICI website.
